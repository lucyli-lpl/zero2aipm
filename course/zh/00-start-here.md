# 模块 0 · 从这里开始

## 为什么有这门课

2026 年 3 月，我是一个做了六年金融科技的产品经理，简历上有一段空窗期，收藏夹里塞满了 AI 文章。我已经"关注 AI"好几个月了。真正改变局面的不是又读了一篇文章，而是那一周：我暂停投简历，动手做了三个小 AI 产品，并且每天记下自己做了什么、哪里出了问题。

六周后，我拿到了 AI 产品经理的 offer。这门课就是我走过的路，整理过后让你走得更快。

开始之前，有两件事要知道：

- **这门课教的是路径和方法，不是一套固定的知识。** AI 工具和热词每隔几个月就换一轮。模块里凡是提到具体工具、模型或趋势的地方，都标了日期。把它们当作方法的例子，学到那里时再确认一下现在是什么情况。
- **边做边学，让 Claude 当你的导师。** 每个模块最后都有一个练习，你自己在自己的文件上完成。Claude 负责讲解、提问、检查你的成果，但不会替你做。

## 课程怎么进行

1. 克隆或 fork 这个仓库，在 Claude Code（或 Claude 桌面 App 的 Code 页）里打开。
2. 输入「开始课程」。Claude 会读取课程说明，问你几个关于背景的问题，然后一次带你学一个模块。
3. 你的成果都放在 `my-journey/` 文件夹：学习日志、名词库、项目笔记和决策记录。Claude 会在 `my-journey/progress.md` 里记录你的进度。
4. 随时可以停。下次输入「继续」，Claude 会从上次停下的地方接着带你。

|---|---|---|
| 0 | 从这里开始 | 一份学习日志 |
| 1 | 把 AI 当导师 | 20 分钟学会任何新概念的方法 |
| 2 | 建立地图 | 个人名词库和一张领域全景图 |
| 3 | 第一周就上线 | 三个上线的小 AI 产品 |

| 5 | 追热点不被淹没 | 判断热点的习惯和一份产品拆解 |
| 6 | 行业速成 | 一页能带进面试的行业简报 |
| 7 | 记录与沉淀 | 能变成方法论、内容和开源作品的笔记 |
| 8 | 进入求职 | 用积累的证据写出的简历和面试准备 |

## 一个习惯：学习日志

我做过最有用的一件事，是用一个普通表格每天记日志。一件事一行，五列：

| 日期 | 做了什么 | 进度 | 备注 | 资料和感悟 |
|---|---|---|---|---|
| 03-13 | 在无代码平台做智能客服 Agent | 已完成 | | 发布上线了，工作流终于跑通 |
| 03-11 | 用 Ollama 和 Docker 搭本地 RAG | 进行中 | 外网一直断 | 模型拉下来了，还没组装 |
| 03-11 | 看 LoRA 微调的视频 | 已完成 | 成本高，没实际做 | 知道它是什么、什么时候值得用 |

它有用的原因：

- 在"好像什么都没干"的日子，进度也看得见。
- "备注"那一列记的是事情卡住的原因。几个月后回头看，这些最有价值，因为它告诉你哪些可以跳过。
- 它会变成你写简历、准备面试、分享经历的原材料。

保持简单就好。一份每天都更新的朴素日志，胜过一份精美但放弃了的。

## 练习

和 Claude 一起完成：

1. 用两三句话告诉 Claude 你的背景：现在做什么、对 AI 了解多少、为什么想转做 AI 产品。
2. Claude 会用 `templates/` 里的模板创建 `my-journey/learning-log.md`。写下第一条：今天为了开始这门课做了什么。
3. 补全一句话：「六周后，我希望能拿出 ___。」要写别人看得见的东西，比如一个上线的产品、一篇拆解文章、一场通过的面试。Claude 会把它放在日志最上面。

## 自测

- 你能用一句话说清楚，为什么这门课给工具和趋势标日期吗？
- 你的日志放在一个你每天真的会打开的地方吗？
- 你的六周目标，是别人也能看到的东西吗？

## 我的经历

我日志里的第一条，是一门免费的 AI 入门课。第二条是提醒自己：别再每天投五份简历了，周末去做一个东西。真正起作用的是第二条。
