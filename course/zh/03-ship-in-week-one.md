# 模块 3 · 第一周就上线

## 为什么学这个

整门课都是围绕这个模块搭起来的。我最大的遗憾，是在动手之前"学 AI"学了太久。几个月的阅读几乎没留下能拿出手的东西。而第一个动手的周末，就换来了一个上线的产品、对 RAG 和提示词的真正理解，以及一个后来每场面试都在讲的故事。

动手能做到三件读书做不到的事：

- 逼你去学真正需要的概念，而且是按需要的顺序学。
- 给你失败。产品判断力就是从失败里来的。
- 给你证据。"我做出来并上线了"在任何面试里都胜过"我研究过"。

## 方法

### 用三个问题选题

每个项目想法，都回答这三个问题：

1. **这是谁的真实问题？** 最好是你自己的，或者你非常熟悉的。你会懂用户，讲故事时也最真。
2. **AI 在这里做什么？非用 AI 不可吗？** 如果一个表单或一张表格就能解决，换一个题目。
3. **两周内能上线第一个版本吗？** 不能就砍范围，砍到能为止。

### 三个项目要互补

每个项目练一块不同的肌肉：

| 项目 | 练什么 | 例子 |
|---|---|---|
| 一个有知识和人设的 Agent | AI 设计：提示词、知识库、边界，以及 Agent 拒绝做什么 | 在无代码 Agent 平台上做一个餐厅客服 Agent |
| 一个全栈应用 | 上线能力：界面、后端、数据库、部署 | 一个调用模型 API 的小网页应用或小游戏 |
| 一个需要做产品形态决策的产品 | 产品判断：为什么是这个形态、给谁用 | 一个出现在用户本来就在的地方的工具（小程序、bot、邮件） |

### 先易后难

第一个项目用无代码 Agent 平台，你可以专注在提示词、知识和工作流上，不用跟代码较劲。第二、三个项目换成 AI 编程工具，做真正的部署。做完三个，你应该把每一步都走过一遍：描述产品、设计界面、生成代码、连数据库、部署、分享链接。

### 上线的意思是：别人能打开链接

在你电脑上能跑不算上线。别人不能通过一个链接打开，就还不算数。

### 每个项目写一份决策记录

一页纸，五个标题：

1. 问题和用户
2. AI 做什么，以及刻意不做什么
3. 一个决策和它的取舍（"我选了 X 而不是 Y，因为……"）
4. 哪里出了问题，怎么修好的
5. 如果今天重做，我会改什么

面试官问决策多过问功能。这份记录就是你要讲的内容。

### 没有 AI 项目？做一个，不要编一个

很多人想转 AI 产品，第一反应是在简历上"包装"一个 AI 项目。这条路走不通。面试官对 AI 项目一定会追问细节："为什么这么设计？""效果怎么评估的？""哪里出过问题？"编出来的项目，两三个问题就露底。

真正有用的，是把上面的方法走一遍：选一个真实问题，两周内做出能打开的第一版，写好决策记录。这样简历上的每一句话，你都答得出背后的"为什么"。

挑项目时，再用三条检查它在面试里站不站得住：

- **有取舍可讲**：你做过至少一个"选 X 不选 Y"的决定。
- **有评测可讲**：你知道怎么判断它做得好不好，哪怕只是 20 条测试问题。
- **有失败可讲**：你知道它在哪里会出错，以及你是怎么处理的。

润色和编造的区别也在这里。把真实做过的事写得更清楚、更有分量，是润色；写你没做过的事，是编造。

## 工具快照（2026 年 3 月，请确认现在的情况）

这是我当时用的。你读到这里时，大概有好几个已经变了。选工具之前让 AI 导师查一下现在的情况。

| 环节 | 我当时用的 |
|---|---|
| 思考和写作用的对话模型 | Claude（Sonnet 4.6 及以上） |
| 无代码 Agent 平台 | 扣子（Coze） |
| 界面和交互设计 | Stitch 配合 Google AI Studio，或 v0 |
| 写代码 | Claude Code、Cursor |
| 国内便宜的模型 API | 硅基流动（GLM、DeepSeek 系列模型） |
| 版本管理 | GitHub |
| 免费数据库 | Supabase |
| 免费部署和域名 | Vercel |

## 练习

1. 告诉 AI 导师你的情况和三个项目想法。AI 导师会用三个问题逐个过一遍，帮你选出一组互补的项目。
2. 第一个项目，在 AI 导师帮助下写一段需求描述，然后做出来。卡住时 AI 导师会帮你，但决定由你来做。
3. 放到线上，把链接贴进学习日志。
4. 用 `templates/decision-record.md` 在 `my-journey/projects/<项目名>.md` 写决策记录。
5. 第二、三个项目重复以上步骤。每次开始前问 AI 导师："上一个项目没练到什么？"

## 自测

- 陌生人能通过链接打开你的三个产品吗？
- 每个项目，你能用一句话说出一个决策和它的取舍吗？
- 哪个项目让你学到最多？是你预想的那个吗？

## 我的经历

2026 年 3 月中旬，我暂停投简历，用一个周末在无代码平台上做了一个蟹煲餐厅的客服 Agent。我家里人做餐饮，我很懂这个用户。我给它设定了俏皮的卡通人设，因为我想象它的顾客是小朋友。两天后，我用 Claude、v0 和 Cursor 做出了一个世界观网站加小游戏，上线了。接着我做了一个每天只推一条 AI 资讯的小程序，因为我想要一个主动来找我的东西，而不是一个要我自己去刷的信息流。这个产品形态的决策，后来成了我面试里最好的回答之一。

这个小程序也正好说明了方案过时得有多快。2026 年初，用带推送的小程序是合理的选择。到了 2026 年底，一个个人 bot 或者一个定时任务就能做到同样的事，工作量小得多。留下推理过程，接受方案会变。
